Политика конфиденциальности MiniCord

Действует с 1 ноября 2026 года

Что такое MiniCord

MiniCord — частный мессенджер для небольшой компании друзей. Он работает на собственном сервере владельца и не используется в коммерческих целях.

Какие данные мы храним

Логин, пароль (только в виде хэша), то, что пользователь сам указывает в профиле, сообщения и файлы, которые он отправляет. Почту — только если пользователь сам её привязал для восстановления доступа.

Данные из подключённых сервисов (Google / YouTube и другие)

Если пользователь подключает к профилю YouTube, MiniCord один раз запрашивает у Google доступ только на чтение (youtube.readonly) и получает идентификатор и название его канала. Эти данные показываются в профиле пользователя, чтобы друзья могли перейти на его канал.

MiniCord не хранит токены доступа Google, не получает доступ к видео, комментариям, подпискам или другим данным аккаунта, ничего не публикует от имени пользователя и не передаёт полученные данные третьим лицам. Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования об ограниченном использовании (Limited Use).

Удаление данных

Подключённый сервис можно отключить в любой момент: Настройки → Интеграции → крестик у подключения. Данные о нём сразу удаляются с сервера. Доступ MiniCord также можно отозвать на странице myaccount.google.com/permissions.

MiniCord Privacy Policy

Effective November 1, 2026

About MiniCord

MiniCord is a private messenger for a small group of friends. It runs on the owner's own server and is not used for commercial purposes.

Data we store

Username, password (hashed only), profile information the user enters, and the messages and files they send. An email address is stored only if the user adds it for account recovery.

Data from connected services (Google / YouTube and others)

When a user connects YouTube to their profile, MiniCord requests read-only access (youtube.readonly) once and retrieves the ID and title of the user's channel. This is shown on the user's profile so friends can visit the channel.

MiniCord does not store Google access tokens, does not access videos, comments, subscriptions or any other account data, never posts on the user's behalf, and does not share this data with third parties. MiniCord's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

A connected service can be removed at any time in Settings → Integrations. Its data is deleted from the server immediately. Access can also be revoked at myaccount.google.com/permissions.

Contact

For any questions, contact the administrator of your MiniCord server.
